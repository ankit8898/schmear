# Code of conduct

schmear follows [Mozilla's Community Participation Guidelines](https://www.mozilla.org/en-US/about/governance/policies/participation/) in every project space: issues, pull requests, reviews and commits.

Report a violation privately to the maintainer, [kevin1chun](https://github.com/kevin1chun), not in a public issue. Reports go to the schmear maintainer, not to Mozilla, and are kept confidential.
